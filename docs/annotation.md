# 自建足球场关键点数据集(应对多机位)

公开模型 `football-field-detection-f07vi` 在你的场景「效果不行」,根因是分布偏移
(它是在 DFL 转播素材上训的)。本方案**在公开模型基础上微调**,而不是从零训:拿公开
数据 + 你自采标注,一起训练,把模型拉回你的多机位场景。

代码链路已就绪:`scripts/train.py`(下载公开数据 + 训练)+ `detector_type: yolo`。
你缺的只有标注这一步。

---

## 0. 关键:标注顺序必须等于 `vertices` 顺序

32 个关键点的顺序已经由 [configs/soccer.py](../pitch_view/configs/soccer.py) 的
`vertices` 固定,并与公开模型一致。**同一个物理点必须永远标成同一个序号**,否则单应性
直接错乱。

32 点语义顺序(0 起;球场长轴 x=12000cm、短轴 y=7000cm):

| 序号 | 物理点 | 序号 | 物理点 |
|---|---|---|---|
| 0 | 左上角点 | 16 | 中线与下边线交点 |
| 1–2 | 左边线:禁区上边 / 小禁区上边 | 17–20 | 右禁区前缘四点 |
| 3–4 | 左边线:小禁区下边 / 禁区下边 | 21 | 右罚球点 |
| 5 | 左下角点 | 22–23 | 右小禁区前缘两角 |
| 6–7 | 左小禁区前缘两角 | 24 | 右上角点 |
| 8 | 左罚球点 | 25–28 | 右边线:禁区/小禁区上下四点 |
| 9–12 | 左禁区前缘四点 | 29 | 右下角点 |
| 13 | 中线与上边线交点 | 30–31 | 中圈左右两点 |
| 14–15 | 中圈上下两点 | | |

规律:先左球门区(角点→边线→小禁区→罚球点→禁区),再中线+中圈,再右球门区(镜像),
最后中圈左右。**不用背坐标**——坐标已写死在 `vertices` 里,标注时只关心「这是第几号点」。

---

## 1. 建标注工程(定义关键点 schema)

用 **Roboflow Annotate**(在线、免费、原生关键点+可见性、一键导出 YOLO 格式)或 CVAT。

1. 新建 project,类型选 **Keypoint Detection**。
2. 新建一个类 `pitch`,**按上表顺序定义 32 个关键点**。这一步把顺序定死。
3. 之后工具会引导你 0→31 逐个标注。

## 2. 采数据(转播素材抽帧)

从你的转播/多机位视频抽帧,覆盖:不同机位(主摄全景/特写/底线/航拍)、不同变焦、
不同光照/天气/球场、比分条/台标/球员遮挡。**先 300~500 张跑通,再按效果加到
1000~2000**。以全景镜头为主;特写镜头标不全就跳过或只标可见部分。

## 3. 标注(每张 32 点)

- 可见点 → 标位置,可见性 = **2**
- 被球员/台标挡住但位置可判 → 标遮挡,可见性 = **1**
- 画面外/看不到 → 跳过,可见性 = **0**(YOLO 里坐标填 0,不参与 loss)
- 顺序一致 + 位置精度 > 数量。熟练后约 2–3 分钟/张。

## 4. 导出 + 训练

导出 **YOLO keypoint** 格式,每行一条:

```
0 cx cy w h  kx1 ky1 v1  kx2 ky2 v2  ...  kx32 ky32 v32
```

(bbox + 32×(x, y, 可见性),全部归一化到 0~1。)

**联合训练**:公开数据集(用 `scripts/train.py --download` 拉到本地)+ 你的标注,混在一起
训,保留公开模型学到的「找关键点」能力,再把你的数据把它拉回你的场景。

```bash
# 先拉公开数据集做基底
python3 scripts/train.py --download --epochs 100 --model yolov8x-pose.pt
# 再把你标注的数据并入 data.yaml 的 train 目录,继续微调
```

## 5. 接入

`scripts/train.py` 训完发布到 `models/pitch_keypoints.pt`；
[court_detector.yaml](../config/court_detector.yaml) 默认:

```yaml
detector_type: yolo
model_path: "models/pitch_keypoints.pt"
```

其余单应性/top-down/发布代码不用改(接口已预留)。

## 附:两条路怎么选

| 场景 | 用哪条路 | 说明 |
|---|---|---|
| 固定机位、视角恒定 | `homography` | 四点标定一次 → 恒定单应性,无需模型。见 `scripts/calibrate_gui.py` |
| 转播/多机位、视角逐帧变 | `yolo`(微调) | 本文件的流程 |

标定工具:
- **Qt GUI**(推荐):`scripts/calibrate_gui.py` —— 左图直播/右图二维图,「开始标定」
  暂停一帧,两边各点 4 点后「计算保存」。
- **无头兜底**:`scripts/calibrate.py --points ...`(直接给四角像素点)。

详见 [training.md](training.md) 与两个脚本的文档字符串。
